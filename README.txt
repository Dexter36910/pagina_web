Software Interactivo con Temática Prehispánica en México
Descripción del Sistema
El proyecto "Software Interactivo con Temática Prehispánica en México" es una aplicación web educativa diseñada para difundir conocimientos sobre las principales culturas prehispánicas de México mediante recursos interactivos. El sistema permite a los usuarios acceder a información histórica, cultural y educativa a través de una interfaz amigable y accesible desde cualquier navegador web.

La plataforma busca fomentar el aprendizaje de la riqueza cultural mexicana utilizando tecnologías web modernas y servicios en la nube para garantizar disponibilidad y accesibilidad.

Objetivos del Sistema
Difundir información sobre las culturas prehispánicas de México.

Proporcionar una experiencia de aprendizaje interactiva.

Facilitar el acceso a contenidos educativos mediante internet.

Implementar buenas prácticas de desarrollo, despliegue y seguridad informática.

Requisitos Previos
Antes de instalar el proyecto es necesario contar con:

Node.js versión 18 o superior.

MySQL Server.

Git.

Navegador web actualizado.

Instrucciones de Instalación
1. Clonar el repositorio
git clone https://github.com/usuario/software-prehispanico.git
2. Acceder al directorio del proyecto
cd software-prehispanico
3. Instalar dependencias
npm install
4. Configurar variables de entorno
Crear un archivo .env en la raíz del proyecto:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=*******
DB_NAME=prehispanico
PORT=3000
5. Configurar la base de datos
Crear la base de datos MySQL:

CREATE DATABASE prehispanico;
Importar las tablas correspondientes del proyecto.

6. Ejecutar el servidor
npm start
o

node server.js
7. Acceder al sistema
Abrir el navegador y dirigirse a:

http://localhost:3000
